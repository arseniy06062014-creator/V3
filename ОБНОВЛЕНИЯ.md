# Как выпускать обновления BeastLauncher

1. Измените код и **поднимите версию** в `package.json` (например, `0.3.0` → `0.3.1`).
2. Загрузите изменения в ветку `main` репозитория на GitHub.
3. GitHub сам соберёт установщик и создаст релиз `v0.3.1` (вкладка Actions → Releases).
4. У игроков лаунчер в течение 30 минут (или при следующем запуске) покажет окно
   «Доступно обновление» → кнопка «Обновить» → «Перезапустить».

Важно:
- Репозиторий должен быть **публичным**, иначе лаунчеры игроков не смогут скачать обновление.
- Если версия в `package.json` не изменилась, новый релиз не создаётся.
- Первый раз игроки скачивают `BeastLauncher-Setup-x.y.z.exe` со страницы Releases. Дальше обновляются сами.
- Папка с настройками, модами и сборками (`%AppData%\.beastlauncher`) при обновлении не трогается.
